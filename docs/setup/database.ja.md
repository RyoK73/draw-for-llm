# データベース

データベースはSupabase(Postgres)です。
マイグレーションは`supabase/migrations/`、シードデータは`supabase/seed.sql`にあります。

## ローカルDB

| コマンド          | 内容                                                       |
| ----------------- | ---------------------------------------------------------- |
| `pnpm db:start`   | ローカルのSupabaseを起動します(Dockerが必要です)。         |
| `pnpm db:status`  | ローカルのURLとキーを表示します。                          |
| `pnpm db:reset`   | マイグレーションと`seed.sql`からローカルDBを作り直します。 |
| `pnpm db:stop`    | ローカルのSupabaseを停止します。                           |
| `pnpm db:version` | Supabase CLIのバージョンを表示します。                     |

### ローカルの主なポート

`supabase/config.toml`で定義されています。

| サービス                   | ポート |
| -------------------------- | ------ |
| API                        | 54321  |
| DB                         | 54322  |
| Studio                     | 54323  |
| local_smtp(ローカルメール) | 54324  |

## マイグレーション

| コマンド             | 内容                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------- |
| `pnpm db:new <名前>` | 新しいマイグレーションファイルを作成します。                                           |
| `pnpm db:push`       | リンク済みのリモートプロジェクトにマイグレーションを適用します。DBのリンクが必要です。 |
| `pnpm db:pull`       | リモートプロジェクトのスキーマをマイグレーションとして取得します。                     |

## 型の生成

型は`src/supabase/utils/database.types.ts`に出力されます。
スキーマを変更したら、必ず再生成してください。

| コマンド              | 生成元                                                    |
| --------------------- | --------------------------------------------------------- |
| `pnpm type:gen-local` | ローカルDB                                                |
| `pnpm type:gen`       | リモートプロジェクト(`.env.local`の`PROJECTID`が必要です) |
